md 파일 여는 법 (윈도우·맥)

MDnote 안내 글 · 읽는 데 3분

파일 이름 끝이 .md인 파일을 열었더니 #, *, - 같은 기호가 잔뜩 섞인 글이 나왔다면, 파일이 깨진 게 아닙니다. 그 기호가 서식입니다. 제대로 보여 주는 프로그램으로 열면 제목·목록·표가 정돈된 문서가 됩니다.

md 파일이 뭔가요?

Markdown(마크다운) 문서입니다. 워드처럼 서식을 버튼으로 정하는 대신, 글 앞뒤에 간단한 기호를 붙여 서식을 표현합니다. 예를 들어 # 제목은 큰 제목, **중요**는 굵은 글씨, - 항목은 목록입니다. ChatGPT, Claude 같은 AI 도구와 노션, GitHub가 이 형식으로 문서를 내보내기 때문에 요즘 부쩍 자주 보게 됩니다.

메모장이나 텍스트 편집기는 이 기호를 해석하지 않고 그대로 보여 줍니다. 그래서 "깨져 보이는" 것입니다.

방법 1. MDnote로 열기 (추천)

  1. MDnote를 내려받아 설치합니다. 윈도우는 setup.exe, 맥은 .dmg 파일입니다.
  2. 설치가 끝나면 .md 파일이 MDnote에 자동으로 연결됩니다. 파일을 더블클릭하세요.
  3. 정돈된 문서가 바로 보입니다. 왼쪽 목차로 이동하고, 고칠 곳이 있으면 위쪽 편집을 누르면 됩니다.

설치가 꺼려진다면 브라우저 버전을 열고 파일을 창 위로 끌어다 놓으세요. 설치 없이 바로 읽을 수 있습니다.

방법 2. 이미 있는 프로그램으로 열기

프로그램가능 여부비고
메모장 / 텍스트 편집기열리지만 기호가 그대로 보임읽기 불편
워드 / 한글텍스트로만 열림서식이 적용되지 않음
Visual Studio Code가능 (미리보기 기능)개발 도구라 설정이 복잡
MDnote더블클릭 한 번읽기 전용 화면이 기본

"연결 프로그램"이 다른 프로그램으로 바뀌었을 때

윈도우에서 .md 파일을 우클릭 → 연결 프로그램 → 다른 앱 선택 → MDnote를 고르고 "항상 이 앱 사용"에 체크하세요. 맥에서는 파일을 선택하고 Cmd+I → 다음으로 열기 → MDnote → 모두 변경을 누르면 됩니다.

자주 묻는 질문

md 파일을 열면 바이러스 위험이 있나요? 없습니다. md 파일은 순수한 글자 파일이라 실행되는 코드가 들어갈 수 없습니다. MDnote는 문서 안의 HTML이나 스크립트도 글자로만 표시합니다.

휴대폰에서도 열 수 있나요? 휴대폰 브라우저로 브라우저 버전을 열고 파일을 선택하면 읽을 수 있습니다.

MDnote는 .md 파일을 더블클릭 한 번에 깔끔한 문서로 보여 주는 무료 프로그램입니다. 회원가입도, 서버도 없습니다.
