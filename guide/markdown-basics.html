마크다운 10분 문법

MDnote 안내 글 · 읽는 데 3분

마크다운은 외울 게 별로 없습니다. 아래 여덟 가지만 알면 AI가 준 문서를 읽고 고치는 데 충분합니다. MDnote의 나란히 보기에서 왼쪽에 입력하면서 오른쪽 결과를 보면 10분 안에 손에 익습니다.

1. 제목: # 기호

# 하나면 큰 제목, 두 개면 중간 제목, 세 개면 작은 제목입니다. # 뒤에는 꼭 한 칸을 띄우세요.

# 보고서 제목
## 1. 개요
### 1-1. 배경

2. 문단과 줄바꿈: 빈 줄

문단을 나누려면 사이에 빈 줄을 하나 넣습니다. 그냥 Enter 한 번은 같은 문단으로 이어집니다. 이걸 몰라서 줄바꿈이 안 된다고 느끼는 분이 가장 많습니다.

3. 강조: 별표

**굵게** → 굵게, *기울임* → 기울임, ~~취소선~~ → 취소선.

4. 목록: - 와 1.

- 사과
- 배
  - 신고배 (앞에 공백 두 칸이면 한 단계 안으로)

1. 물을 끓인다
2. 면을 넣는다

5. 체크리스트: - [ ]

- [ ] 할 일은 빈 상자, - [x] 한 일은 완료입니다. MDnote에서는 읽기 화면의 상자를 클릭하면 파일도 같이 바뀝니다.

6. 링크와 이미지

링크는 [보이는 글](주소), 이미지는 앞에 느낌표를 붙여 ![설명](이미지 주소)입니다. 주소만 그대로 적어도 링크가 됩니다.

7. 표: 세로줄

| 항목 | 수량 |
| --- | --- |
| 연필 | 3 |
| 공책 | 2 |

둘째 줄의 ---가 "여기가 표"라는 표시입니다. 칸 너비는 맞추지 않아도 됩니다.

8. 인용과 코드

줄 앞에 >를 붙이면 인용문, 글 안에서 `(키보드 숫자 1 왼쪽)로 감싸면 코드나 파일 이름처럼 보입니다. 여러 줄은 ``` 세 개로 위아래를 감쌉니다.

그 외에 알아 두면 좋은 것

  • ---만 있는 줄은 가로 구분선입니다.
  • 기호를 글자 그대로 쓰고 싶으면 앞에 \를 붙입니다. 예: \*별표\*
  • 워드처럼 글자 색, 글꼴, 가운데 정렬은 기본 마크다운에 없습니다. 그래서 어디서 열어도 모양이 같습니다.

MDnote를 처음 실행하면 이 내용을 직접 고쳐 보며 연습할 수 있는 Markdown 사용설명서가 열립니다.

MDnote는 .md 파일을 더블클릭 한 번에 깔끔한 문서로 보여 주는 무료 프로그램입니다. 회원가입도, 서버도 없습니다.
