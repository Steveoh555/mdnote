노션에서 내보낸 파일 읽기

MDnote 안내 글 · 읽는 데 3분

노션에서 내보내기를 하면 .zip 파일 하나를 받게 됩니다. 압축을 풀면 .md 문서와 이미지 폴더가 나오는데, 메모장으로 열면 기호만 보입니다. MDnote로 폴더째 열면 노션에서 보던 것과 거의 같은 모습으로 읽을 수 있습니다.

1. 노션에서 내보내기

  1. 내보낼 페이지 오른쪽 위 ··· → 내보내기.
  2. 내보내기 형식은 Markdown & CSV, "하위 페이지 포함"을 켭니다.
  3. 받은 ZIP 파일을 우클릭 → 압축 풀기.

2. MDnote로 폴더 열기

MDnote를 열고 왼쪽 폴더 열기를 눌러 압축을 푼 폴더를 고릅니다. 하위 페이지까지 모두 목록에 나오고, 클릭해서 넘겨가며 읽을 수 있습니다. 파일 이름 뒤에 붙는 긴 영문·숫자 코드는 노션이 붙인 페이지 ID이니 신경 쓰지 않아도 됩니다.

3. 표, 체크박스, 콜아웃은 어떻게 보이나요?

노션 요소내보낸 결과MDnote에서
제목, 글머리, 번호 목록그대로정상 표시
할 일(체크박스)- [ ]클릭해서 체크 가능
표마크다운 표정상 표시. 데이터베이스는 CSV로 따로 나옴
콜아웃인용문(>)회색 세로선 인용으로 표시
토글본문으로 펼쳐짐항상 펼쳐진 상태
이미지같은 폴더 안 이미지 파일폴더째 열면 표시. 파일 하나만 옮기면 안 보임

4. 이미지가 안 보일 때

노션 md 파일은 이미지를 페이지이름/그림.png처럼 상대 경로로 가리킵니다. md 파일만 다른 곳으로 옮기면 이미지 폴더와 연결이 끊깁니다. 압축 푼 폴더를 통째로 두고 그 안에서 여세요.

5. 내보낸 문서를 다른 사람에게 줄 때

MDnote의 내보내기 → PDF를 쓰면 노션 계정이 없는 사람에게도 같은 모양으로 전달할 수 있습니다. HTML로 내보내면 브라우저만 있으면 열리는 파일 하나가 됩니다.

MDnote는 .md 파일을 더블클릭 한 번에 깔끔한 문서로 보여 주는 무료 프로그램입니다. 회원가입도, 서버도 없습니다.
