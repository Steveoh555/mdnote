ChatGPT 답변을 md 파일로 저장하고 읽는 법

MDnote 안내 글 · 읽는 데 3분

AI가 써 준 보고서·요약·계획서를 채팅창에 두면 다시 찾기 어렵습니다. .md 파일로 저장해 두면 파일 하나로 보관되고, MDnote로 열면 채팅창에서 보던 것과 같은 모습으로 읽을 수 있습니다.

왜 md인가요?

ChatGPT와 Claude는 답변을 마크다운 형식으로 만듭니다. 화면에서 보이는 제목, 굵은 글씨, 표, 목록이 모두 마크다운 기호로 되어 있습니다. 그래서 그대로 md 파일로 저장하면 서식이 하나도 손실되지 않습니다. 워드에 붙여 넣으면 표와 목록이 어긋나는 경우가 많지만, md는 원본 그대로입니다.

1. 답변을 마크다운 원문으로 복사하기

  • ChatGPT: 답변 아래의 복사 아이콘을 누르면 마크다운 원문이 복사됩니다. 마우스로 드래그해서 복사하면 서식이 사라지니 아이콘을 쓰세요.
  • Claude: 답변 아래 복사를 누르거나, 긴 문서는 오른쪽 아티팩트 창에서 내려받기를 누르면 바로 .md 파일로 받아집니다.
  • Claude Code·ChatGPT 프로젝트: 작업 폴더에 md 파일이 자동으로 생깁니다. 이 경우 복사할 필요 없이 폴더를 그대로 열면 됩니다(아래 4번).

2. md 파일로 저장하기

MDnote를 열고 새 문서를 누른 뒤 붙여넣기(Ctrl+V)하고 Ctrl+S로 저장하면 끝입니다. 파일 이름 뒤에 .md가 자동으로 붙습니다.

MDnote가 없다면 메모장에 붙여 넣고 저장할 때 파일 이름을 보고서.md처럼 쓰고, "파일 형식"을 모든 파일로 바꾸세요. 그렇지 않으면 보고서.md.txt가 됩니다.

3. 깔끔하게 다시 읽기

저장한 파일을 더블클릭하면 MDnote가 정돈된 문서로 보여 줍니다. 오른쪽 위 편집을 누르면 AI 답변에서 틀린 부분을 바로 고칠 수 있고, 내보내기로 PDF나 HTML로 바꿀 수도 있습니다.

4. 답변이 여러 개라면 폴더째 열기

md 파일을 한 폴더에 모아 두고 MDnote 왼쪽의 폴더 열기를 누르면 폴더 안의 모든 문서가 목록으로 나옵니다. 클릭해서 넘겨가며 읽으면 되니, 답변 수십 개를 관리하기에 좋습니다. Claude Code처럼 작업 폴더에 md를 쌓아 두는 도구를 쓴다면 그 폴더를 열어 두세요.

팁: 파일 이름 규칙

2026-09-16_마케팅계획_v2.md처럼 날짜와 주제를 앞에 두면 폴더 목록에서 날짜순으로 정렬됩니다.

MDnote는 .md 파일을 더블클릭 한 번에 깔끔한 문서로 보여 주는 무료 프로그램입니다. 회원가입도, 서버도 없습니다.
