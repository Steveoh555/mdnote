# MDnote 기획서

작성일: 2026-09-10 · 상태: 확정 (기획회의 1차 완료)

## 1. 목적
클로드(Claude) 작업 중 생성되는 많은 `.md` 파일을 **깔끔하고 가독성 좋게 읽고**, 필요할 때 **바로 편집**할 수 있는 전용 프로그램.
기존 프로그램으로 열면 서식이 깨지거나 불편한 문제를 해결한다.

## 2. 핵심 원칙
- **읽기 우선**: 파일을 열면 편집창이 아니라 정돈된 읽기 화면이 먼저 뜬다. 편집은 전환해서 한다.
- **필수 기능만**: 로그인, 클라우드 동기화, 실시간 협업, 플러그인은 넣지 않는다.
- **클로드 산출물이 안 깨진다**: 코드 블록, 표, 체크리스트, 중첩 목록, 인용, Mermaid 다이어그램이 정확히 렌더링된다.

## 3. 앱 형태
- 본체는 웹 기술(HTML/CSS/JS)로 한 번만 개발.
- **Tauri**로 감싸 설치형 배포: 윈도우 먼저 → 맥(GitHub Actions로 클라우드 빌드).
- 같은 본체를 **웹사이트**로도 배포: 소개 페이지 + 다운로드 + 브라우저에서 바로 사용 + 광고 1~2개.
- 광고는 웹 버전에만 붙인다. 설치형에는 광고 없음.

## 4. 기능
### 필수
1. `.md` 파일 열기 / 저장 / 다른 이름으로 저장 (설치형: 더블클릭 연결)
2. 보기 모드 3종: 읽기 / 편집 / 나란히
3. 서식 툴바 + 단축키 (굵게, 기울임, 제목, 목록, 링크, 이미지, 코드, 표, 인용)
4. 자동 임시저장 및 복구
5. 찾기 / 바꾸기
6. 목차(개요) 패널, 제목 클릭 이동
7. 내보내기: HTML, PDF(인쇄)
8. 라이트 / 다크 테마
9. GitHub식 마크다운(GFM) 완전 지원 + 코드 하이라이트
10. 한국어 / 영어 UI
11. 글자 수 / 단어 수 / 읽기 시간

### 선택 (포함 확정)
- **폴더 목록 사이드바**: 폴더를 열면 안의 `.md` 파일들이 왼쪽에 나열되고 클릭해 넘겨가며 읽는다.
- **Mermaid 다이어그램 렌더링**

### 제외
- 스크롤 동기화, 집중 모드, 이미지 붙여넣기 자동 삽입, 최근 파일 목록 (추후 검토)

## 5. 디자인 톤앤매너 (2026-09-10 2차 확정)
1차 "종이와 잉크"(아이보리 + 세리프 + 와인색) 시안은 **클로드 브랜드와 똑같아 보여 폐기**. `design/round1-rejected/` 보관.
사람이 만든 실제 제품처럼 보이는 중성 톤으로 재확정.

### 라이트 = 시안 A "Native Neutral" (`design/r2-A-native-neutral.png`)
- 본문 영역 흰색 `#FFFFFF`, 사이드바·툴바 연회색 `#F3F3F3`, 글자 `#222222`, 선 `#E3E3E3`.
- 강조색 단 하나: 슬레이트블루 `#3A6EA5` (선택 파일, 활성 버튼, 링크, 체크박스).
- 글꼴: 시스템 산세리프 (Pretendard / Segoe UI), 본문 16px, 줄간격 1.7, 본문 폭 최대 ~700px.
- 코드 블록 배경 `#F6F8FA`, 언어 라벨 표시.

### 다크 = 시안 C "Graphite" (`design/r2-C-graphite-dark.png`)
- 사이드바 `#1F2023`, 본문 영역 `#26272B`, 글자 `#E4E4E7`, 보조 글자 `#9A9AA1`, 선 `#35363B`.
- 강조색: 라이트와 같은 계열의 밝은 슬레이트블루 (다크 대비용으로 조정).

### 공통 규칙
- 보기 전환은 **박스형 세그먼트** (Read | Edit | Split), 활성 셀은 강조색 채움.
- 상단 오른쪽 아이콘: **검색 · 설정 · 더보기**. 내보내기·테마는 더보기/설정 메뉴 안.
- 세리프 금지, 아이보리·크림·베이지 금지, 와인·테라코타 금지, 보라·네온·그라데이션·글래스 금지.
- 윈도우 11 창틀과 자연스럽게 어울리는 밀도.

## 6. 화면 구성 (2026-09-13 수정: 목차를 폴더 옆으로 이동)
```
┌──────────────────────────────────────────────────────┐
│ 상단 바: 파일명 · [읽기|편집|나란히] · 검색 · 설정(톱니) · 더보기 │
├──────────┬──────────┬────────────────────────────────┤
│ 폴더 목록 │   목차    │        본문 (읽기/편집/나란히)      │
│ (접기 가능)│(접기 가능) │                                │
├──────────┴──────────┴────────────────────────────────┤
│ 하단 바: 글자 수 · 단어 수 · 읽기 시간 · 저장 상태        │
└──────────────────────────────────────────────────────┘
```
- 첫 실행 시 `Markdown_사용설명서.md`가 **나란히 보기**로 열려 문법을 실습하며 배운다. 더보기 메뉴에서 언제든 다시 열 수 있다.
- 메뉴 구조 (2026-09-13 확정, '⋯ 더보기' 제거): 파일 열기·폴더 열기·새 문서는 왼쪽 파일 패널 상단 글자 버튼 / 저장·다른 이름으로는 편집 툴바 오른쪽 끝(읽기 모드에서 체크박스로 내용이 바뀌면 상단에 저장 버튼만 잠깐 표시) / 상단 오른쪽은 검색 · 내보내기▾(HTML, PDF) · 설정(톱니) / 설정 안에 패널 표시(폴더·목차)와 도움말(사용설명서, 버전).
- 편집 툴바: 실행취소/다시실행 · 굵게/기울임/취소선 · H1/H2/H3 · 글머리/번호/체크리스트 · 링크/이미지/인라인코드/코드블록 · 표/구분선/다이어그램/인용

## 7. 배포·수익
- 웹: Cloudflare Pages 또는 Vercel (무료). 이후 도메인 구매.
- 설치형: GitHub Releases에 윈도우 `.msi/.exe`, 맥 `.dmg` 업로드. 초기엔 서명 없이 배포(경고 감수), 사용자 증가 시 인증서 구매.
- 광고: 구글 애드센스 1~2개 (웹 하단 얇은 띠 + 사이드 1개). 심사 통과를 위해 소개·사용법 페이지 포함.
