# MDnote v0.3.1 보안 평가

- 평가일: 2026-10-20
- 대상: `app/MDnote` main 브랜치(커밋 7d95f5c, v0.3.1), 라이브 사이트 https://mdnote.aiink.kr, 데스크톱(Tauri 2) 소스
- 방법: 소스 전수 검토, 렌더러를 node에서 그대로 재현한 하네스로 악성 Markdown 페이로드 투입(`scratchpad/sec/md-harness.mjs`, `probe-xss.mjs`, `probe-perf.mjs`, `probe-task.mjs`), 라이브 서버 헤더 점검(curl), `npm audit`, Cargo.lock 버전별 GitHub Advisory 조회(cargo-audit 미설치), Tauri/wry/mermaid 라이브러리 소스 확인
- 하지 않은 것: GUI·브라우저 자동화(mermaid 런타임 동작은 라이브러리 소스로만 확인 → 해당 항목은 "코드 근거"로 표기), 설치형 실행 테스트, cargo-audit 설치

## 요약

전체 위험도: **중간(Medium)**. 핵심 공격면인 "악성 .md 파일 → 렌더러 XSS"는 잘 막혀 있다. markdown-it `html:false`, 링크 프로토콜 검증, highlight.js 이스케이프, mermaid `securityLevel: 'strict'`가 모두 실제로 동작함을 확인했고 ReDoS·대용량 문서도 문제없었다. 다만 **설치형의 fs 권한이 `**`(전체 디스크 읽기·쓰기)** 라서 향후 렌더러 쪽에 작은 구멍 하나만 생겨도 곧바로 임의 파일 읽기·쓰기(사실상 코드 실행)로 이어지는 구조이고, mermaid 다이어그램 링크를 통해 **설치형 메인 창이 외부 사이트로 통째로 이동**할 수 있는 경로가 있다. 웹 버전은 GitHub Pages 특성상 보안 헤더가 전혀 없고 `<meta>` CSP도 없다. 또 EUC-KR 등 비UTF-8 파일을 열어 저장하면 내용이 깨지는 무결성 문제가 있다. 공급망 쪽은 `npm audit`에 high 1건(빌드 도구 한정), 서명 없는 설치 파일, SHA 고정 없는 GitHub Actions가 남아 있다.

## 확인된 안전 항목

하네스(`scratchpad/sec/probe-xss.mjs`)로 실제 렌더 결과를 확인한 것:

- **HTML 통과 차단**: `<script>`, `<img onerror>`, `<iframe>`, `<svg onload>`, `<math>` 네임스페이스 혼동 페이로드 모두 텍스트로 이스케이프(`html:false`). 헤딩·표·목록·작업 목록 안에서도 동일.
- **위험 프로토콜**: `javascript:`, `JAVASCRIPT:`, `vbscript:`, `data:text/html`, `file:` 링크/이미지 → 링크로 렌더되지 않음. 엔티티 우회(`&#58;`, `&colon;`, `&#106;`, `&#x73;`)도 디코딩 후 검사되어 차단. 오토링크 `<javascript:...>` 차단.
- **URL 파서 우회 시도**: `<javascript\t:alert(1)>`(꺾쇠 목적지 안의 탭)는 `javascript%09:`로 퍼센트 인코딩되어 나오며 WHATWG URL 파서에서 상대 경로로 해석됨(node `new URL`로 확인). 제로폭 접두어도 동일.
- **속성 탈출**: 링크/이미지 `title`의 따옴표는 `&quot;`, `src`의 따옴표·공백은 퍼센트 인코딩. 코드 펜스 언어 라벨(`js" onclick=`)도 이스케이프.
- **data:image SVG**: `![](data:image/svg+xml,<svg onload>)`는 markdown-it가 거부(이미지 data는 허용 목록에 있어도 꺾쇠 포함 시 파싱 실패). 허용되더라도 `<img>` 안의 SVG 스크립트는 실행되지 않음.
- **linkify**: `evil.com` 같은 퍼지 링크는 `http://`로만 생성, `javascript:` 텍스트는 링크화되지 않음. http(s) 링크에 `target=_blank rel="noopener noreferrer"` 부여 확인.
- **헤딩 id**: `sec-` 접두사로 `constructor`, `__proto__` 등 DOM clobbering 대상 id 생성 불가.
- **mermaid strict**: `securityLevel`은 지시어로 변경 불가, 라벨은 DOMPurify(`ADD_TAGS: foreignobject` 최소 허용), `click … call/callback`은 strict에서 무시(`chunk-SHT3W25Y.mjs:449`), 링크 URL은 `@braintree/sanitize-url` 통과, `_blank`에 `rel=noopener` 자동 부여.
- **highlight.js**: `getLanguage` 검증 후에만 하이라이트, 미지원 언어는 escapeHtml. 병적 입력에서도 1초 미만.
- **작업 목록 토글**: 코드 블록·인용문 안의 `- [ ]`가 체크박스 인덱스를 어긋나게 하는지 확인 → 렌더 5개/소스 정규식 5개로 일치(`probe-task.mjs`).
- **설정 쿼리스트링**: `?view=`는 화이트리스트 검증, `?outline=`은 불리언. `localStorage` 설정은 JSON spread라 프로토타입 오염 없음.
- **Tauri IPC/CSP**: `withGlobalTauri` 미사용, `script-src 'self'`(Tauri가 자체 주입 스크립트에 nonce 부여), `object-src 'none'`, `frame-src 'none'`, `asset:` 프로토콜 비활성(문서 내 상대 경로 이미지로 로컬 파일 읽기 불가). 원격 origin에는 capability가 적용되지 않아 설령 2번으로 외부 페이지가 떠도 파일 API는 못 쓴다. `dragDropEnabled:false`로 드롭 파일 경로 노출 없음. `target=_blank` 새 창 요청은 wry가 차단.
- **Rust**: `launch_file`은 한 번만 소비되는 문자열 반환, 명령 주입·경로 처리 로직 없음. macOS `Opened` 이벤트는 `to_file_path()`로 file URL만 수용. `panic=abort`, `strip`, LTO 릴리스 프로필.
- **CI(pages.yml)**: `contents: read` 최소 권한, `npm ci`로 lockfile 고정 설치.
- **비밀 정보**: 저장소에 토큰·키 없음(`git grep` 확인). 외부 폰트·스크립트·분석 코드 없음(Pretendard는 번들, AdSense는 자리만 있음).
- **라이브 사이트**: HTTP→HTTPS 301, `robots.txt`/`sitemap.xml` 정상, `/app/` 빌드에 inline script 없음.
- **EOL/BOM**: CRLF는 열 때 LF로 정규화하고 저장 시 복원. BOM은 `File.text()`/`TextDecoder` 기본값이 제거하므로 렌더에 영향 없음(단, 저장 시 BOM이 사라지는 사소한 변경).

## 권장 조치 우선순위

1. **fs capability `**` 제거**(1번) — dialog `recursive:true` + Rust에서 launch 경로 `allow_file`. 설치형의 가장 큰 구조적 위험을 없앤다.
2. **SVG 앵커 처리 + 외부 내비게이션 차단**(2번) — `getAttribute('href')`로 판단, `on_navigation`으로 앱 origin 외 이동 거부. 두 줄짜리 수정.
3. **비UTF-8 파일 보호**(3번) — `fatal:true` 디코딩 실패 시 저장 금지/인코딩 재시도. 사용자 데이터 손실 방지.
4. **웹 빌드 `<meta>` CSP + 프레임 버스팅 + referrer 정책**(4번, 11번 내보내기 CSP 포함).
5. **의존성 정리**(5번) — `npm update`로 source-map-js/dompurify 해결, mermaid 12 검토, CI에 `npm audit`·`cargo audit`.
6. **릴리스 공급망**(6번, 17번) — 액션 SHA 고정, `SHA256SUMS`·provenance 첨부, `releaseDraft:true`, 코드 서명 완료 시 사이트의 "경고 무시" 안내 삭제.
7. **원격 이미지 정책**(7번) — CSP `http:` 제거, 원격 이미지 옵트인, 개인정보처리방침 문구 보완.
8. **편집기 특수문자 표시**(8번), 폴더 권한 `read`(9번), 임시본 만료·키 충돌(10번), opener 권한 축소(12번), 상대 링크 처리(13번).
