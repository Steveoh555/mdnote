## 낮은 우선순위

- 원격 이미지 자동 로드(추적 픽셀로 열람 시각·IP 유출 가능) → 외부 이미지 차단 옵션 또는 첫 클릭 후 로드
- RTL·제로폭 문자 미표시(Trojan Source) → highlightSpecialChars
- npm audit: source-map-js(빌드 도구 한정, high), dompurify·katex(mermaid 경유, low). mermaid 12로 올리면 해소
- CI 액션 SHA 미고정, SHA256SUMS·provenance 없음, 버전 4곳 중복
- 접근성: 포커스 링 없음, 파일 트리 aria 없음, 키보드 탐색 불가
- 창 크기·위치 미보존, 자동 업데이트 없음
- 인쇄 시 넓은 표가 `overflow:auto`로 잘림
- 각주·수식·이모지 단축코드 미지원(의도적 제외였으나 명시 필요)
- 내보낸 HTML에 CSP 없음, 검색 하이라이트 `<mark>`가 내보내기에 포함됨

## 안전하다고 확인된 것

HTML 태그·`javascript:`·엔티티·탭·제로폭 우회·속성 탈출·`data:` SVG·자동링크·헤딩 id 충돌 모두 차단. ReDoS 없음(10만 행 855ms). Mermaid securityLevel strict·DOMPurify·콜백 차단 동작. Tauri IPC·CSP·새 창 차단·Rust argv 처리 이상 없음. 읽기 화면 렌더링 품질과 인쇄 PDF 품질은 세 평가자 모두 호평.
