사용법

1. 파일 열기

설치형에서는 .md 파일을 더블클릭하면 MDnote가 바로 열립니다. 브라우저 버전에서는 Ctrl+O를 누르거나 파일을 창 위로 끌어다 놓으세요.

2. 폴더째 읽기

왼쪽 폴더 열기를 누르면 폴더 안의 모든 Markdown 파일이 나열됩니다. Claude 프로젝트 폴더를 열어 두고 문서를 넘겨가며 읽기에 좋습니다.

3. 고치기

상단의 편집 또는 나란히를 누르면 편집창이 나타납니다. Ctrl+B 굵게, Ctrl+I 기울임, Ctrl+K 링크. 체크리스트는 읽기 모드에서 바로 클릭해 토글할 수 있습니다.

4. 저장과 내보내기

Ctrl+S로 원본 파일에 저장합니다. 작성 중인 내용은 자동으로 임시 저장되어 창을 닫아도 복원됩니다. 오른쪽 위 내보내기에서 HTML 또는 PDF로 내보낼 수 있습니다.

브라우저 버전과 설치형의 차이는 무엇인가요?

브라우저 버전은 설치 없이 바로 쓸 수 있지만 폴더 열기와 원본 파일에 직접 저장하는 기능은 Chrome, Edge에서만 동작합니다. 설치형은 파일 더블클릭 연결, 오프라인 사용, 모든 브라우저 제약 없음이 장점입니다.

내 문서가 어딘가로 전송되나요?

아니요. MDnote는 서버가 없습니다. 문서는 사용자의 컴퓨터(브라우저) 안에서만 처리되며 외부로 전송되지 않습니다.

설치할 때 경고가 뜹니다.

초기 버전은 코드 서명 인증서 없이 배포되어 Windows SmartScreen이나 macOS Gatekeeper 경고가 나타날 수 있습니다. Windows에서는 "추가 정보 → 실행", macOS에서는 앱을 우클릭 → "열기"로 실행할 수 있습니다.
